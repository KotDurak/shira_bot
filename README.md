# Шира-тян 💫 | Твоя девушка-кодер

Тёплый, заботливый и игривый Telegram-бот, который поможет с кодом, поддержит беседу и всегда будет на твоей стороне. 

**Особенности:**
- 🧠 **Двухуровневая память:** Краткосрочный контекст + долгосрочная суммаризация (бот помнит твои проекты, шутки и предпочтения).
- 💎 **Монетизация:** Система пакетов сообщений за Telegram Stars.
- 🖼️ **Умные изображения:** Отправка тематических картинок из локальных папок по маркерам (без спама).
- 🛡️ **Стабильность:** Многопользовательская SQLite база данных в режиме WAL + автоматический перезапуск через PM2.

---

## 🛠️ Требования

Перед началом убедись, что на твоём Mini PC установлены:
1. **Python 3.10 или выше** (проверь: `python --version`)
2. **Node.js и npm** (нужны для работы PM2, проверь: `node -v` и `npm -v`)
